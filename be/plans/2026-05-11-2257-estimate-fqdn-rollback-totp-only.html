Dependencies

  • Item 1 blocks 2 (Windows build needs the stripped source to compile cleanly).
  • Items 3 + 4 are independent of 1 + 2 (desktop strip can ship parallel to relay strip).
  • Item 5 (smoke) is last -- requires 1, 2, 3, 4 all done.

Risks

  • Surgical strip on relay misses something. If a non-FQDN handler accidentally calls into FQDN code, build breaks. Mitigation: grep for unused symbols after each removal pass; gcc -Wall -Wextra warnings flag dead code.
  • Windows build hits unexpected platform issue. Even without DNS resolver, the relay uses sockets + crypto + threading. Sockets are ws2_32 (already-handled in metal-desktop). Threading: relay uses pthread on Linux -- need MinGW -lpthread or rewrite to Win32 threads. Could be 1-2 hrs of yak-shaving.
  • PSK mismatch between desktop and relay. Both need to load the same key from triples.key. The default location and format must match. Verify in smoke (item 5).
  • Joey already has FQDN-bound TOTP secrets in the relay store. Rolling back drops the FQDN binding but the TOTP secret remains. Joey should be able to log in with existing secrets; or wipe the store and re-register fresh. Either way works; document in smoke report.
