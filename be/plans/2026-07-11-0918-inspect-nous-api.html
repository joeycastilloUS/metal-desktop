The public verb surface is EXACTLY four: ask, judge, summarize, reconsider.
Requests and responses are NTRP triples carried on the wire from the relay.
The C# edge (acmedev Cloud Run) is the blind REST front; it never sees
keys or plaintext — it forwards triples and returns triples.
This skill is thin. It composes fanout/judge/summarize/reconsider.

Patterns Found

  1. Spec-ahead is real and honest. Every skill CLAUDE.md says so, and the tree proves it — no phantom stubs pretending to work. skill.json's "sources": ["api.c"] is a declared intention, not a lie.
  2. The extraction map is already written. fanout's CLAUDE.md § "Extracted From" names the exact donor symbols: provider_thread is the worker, handle_task is the driver, "fanout is handle_task minus the WebSocket I/O." The port is a lift, not a design.
  3. BYOK is designed to the struct level. fanout CLAUDE.md § "BYO Keys (2026-06-19)": KeyOverride { env, val } on FanoutOpts, precedence per-request override → vault → store → env, RAM-only, never logged. "Blank = internal key" is literally the specified fallthrough — no override entry means providers_resolve_key() resolves the mesh's own key from the prime-side sealed vault. Design artifact: kastil-systems/nous/be/designs/2026-06-18-1932-design-byo-keys.html.
  4. Two serve.c generations. The spec's line references (route_ws_message ~3185) point at the old C:\nous\user\interface\desktop\serve.c; the living engine at C:\tools\metal-de\src\serve.c has drifted (route now at 5182, +2,000 lines, cohere/openai-responses formats, workforce/map/prove verbs). Spec refs need a refresh when api.c gets built.
  5. Reconsider is vaporware on both sides. Spec'd verb, header exists, zero implementation in any tree. It is the only one of the four with no donor code.
