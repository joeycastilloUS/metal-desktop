Plan v2 — metal.de ↔ metal.ce Parity

Settle the contract on metal.ce first — the .pi program model, the Catalog, DoR/DoD — then fold the settled contract into metal.de. Serving the mission: LLM/GPU-free, Zero Cost Intelligence, deterministic from the start.

PLAN — APPROVED 2026-07-10 · FULL ON · BUILD
Supersedes v1 (be/plans/2026-07-02-1117-plan-metal-de-ce-parity.html, 11 boards / ~115 pts). What changed: v1 built metal.de to parity from a seeded a-d-d spec with native tiered execution. v2 keeps that spine but re-centers on the contract, and sequences ce-before-de. Four things this session produced now fold in: (1) the corpus is a .pi program library (33 cards scored, live at joeycastillo.us/metal/pi) — per-slot tiering, the chain-reaction tail is ONE program; (2) the Catalog — patterns + C99 skills as entity types in the live /catalog store (~d awaiting approval); (3) DoR item 5 + DoD item 11 that reach every gated tilde through the shared programs; (4) the decoder (understand()), the dialect translator, and clauderun as the Cold host. v1's P4/P5/P6 (four organs) collapse into one extracted tail. Mark v1 SUPERSEDED in the index.

Intent

Bring metal.de (Desktop Edition) to full parity with metal.ce (Console Edition) — the complete tilde contract executed natively on the operator's desktop, deterministic C at $0.00 where the work is deterministic, escalating per tier where it isn't. The reframe: the thing being ported is a contract (the .pi cards, the Catalog, the DoR/DoD, the shared tail, decoder, translator, Cold host), not a bag of features. A contract that isn't settled cannot be ported without doing it twice and re-opening the ce/de split that forced the P12 absorb. So v2 settles and proves the contract on metal.ce — where it is cheap and where the /catalog store already ships — then metal.de folds the settled contract in as its parity build. Every phase serves the mission: drive to Tier-0, LLM-free, deterministic. Companion design: the .pi Extraction Engine (be/designs/2026-07-10-1444-...) + the Catalog (joeycastillo.us/metal/catalog).

Scope

In

  • Arc A — settle the contract on metal.ce: the .pi card format + parser + per-slot tier dispatch; the shared tail executor extracted once; the six Hot cards sealed; the Catalog (patterns + skills as type= triples in the live store); DoR item 5 + DoD item 11 + the uses: field; the decoder (nous understand()) + RAW/DERIVED IDS; the dialect translator; clauderun revived as the Cold host + atom-diff verifier.
  • Arc B — fold the settled contract into metal.de: the consolidated kastil-systems/metal-desktop repo; route_tilde() at the serve.c:3056 seam replaying .pi cards natively; DE reading the Catalog over the wire (never a repo); the be/ machinery + tail native in DE; identity/auth; the cross-platform floor; relay-dependent tildes; the ~t→tlt binding; the full parity gate with external production verification.
  • The pre-existing DoD drift fix (commands.md 8 items vs help-blocks 10) — gates clean numbering; done in A0.

Out

  • A new catalog format / API — the Catalog is entity types in the store that already ships; no catalog.json schema of our own.
  • Exposing kastil-systems to editions — ever. Patterns/skills reach DE as a sealed projection over the wire (publish the list, seal the source).
  • Writing to a-d-d without operator approval: the Nameplate pattern name, PRACTICES #13, and any a-d-d spec change are proposals (Rule 10).
  • C-native board renderer (v1 vendors Python behind the contract); terminal tab / xterm.js; MCP; silicon console; the far-horizon master-plan (ALF, biRT v3, 38 driver manifests); prime/relay deployment itself (external dependency).

Approach

  1. Contract first, edition second. Arc A settles the .pi + Catalog + DoR/DoD on metal.ce. metal.de's parity is defined as executing that contract — so the contract must exist and be proven before the DE fold. No porting a moving target.
  2. Extract the tail once, not thirty-two times. The chain-reaction tail (scaffold→save→index→telemetry→Latchkey→commit/push→DoD→Signal→pop) is ONE program. Extract it as biRT's common runtime; every .pi card collapses to frontmatter + scaffold + judgment slots.
  3. Publish, don't expose. Patterns + skills become type=pattern/type=skill triples in the live prime /catalog store, published by manifest_export_filtered, sealed by mesh.sealed, served over the wire. DE reads the projection; the source never leaves a-d-d. (Trust governs; the projection move is the new pattern, Nameplate.)
  4. The contract reaches all tildes through shared programs, not per-card edits. DoR item 5 (class-scoped) + DoD item 11 land once in the shared pre-flight and tail; the exemption machinery excludes the 13 dor-exempt utilities for free. The uses: field is written on apply and resolve-checked at DoD.
  5. Prove the smallest seam, then widen by dependency ring. A1 (~config.pi replays at Tier-0 $0, data-driven not hardcoded) proves the whole spine. Then Hot set → Catalog → contract → decoder → translator → Cold host; then the DE fold ring by ring.
  6. No baby steps; production-like from the first move. A-arc runs on the store that already ships and the corpus that already runs; each piece is the real thing at small scale. Fall fast on ce where a miss is a $0 query — never discover the contract's holes inside the DE port.
  7. Plans are wrong by default. This is a v2 hypothesis; the FC full-court press already re-shaped the Catalog once. Unknowns and When To Revisit are first-class below.

Constraints the checklist

  1. Contract before edition. metal.de folds the settled contract; nothing ports until Arc A proves it on ce.
  2. C99 everywhere we own; C# only as foreign-API jackets (the Playwright worker is the sole sanctioned jacket).
  3. Publish, don't expose. Patterns/skills reach editions as a sealed projection of the live /catalog store, over the wire; a-d-d source never leaves origin. No repo access from any edition, ever.
  4. No new catalog format. Entity types in the existing store + manifest_export_filtered + mesh.sealed. Zero new API.
  5. Visibility scoped. Security-domain signatures gated by the policy skill against requester FQDN; public discovery is names + intents only.
  6. The contract reaches all via shared programs. DoR item 5 + DoD item 11 land once in the shared pre-flight/tail, class-scoped; 13 dor-exempt utilities excluded for free; zero per-card edits. uses: written on apply, resolve-checked at DoD.
  7. Tier is data, not code. tier: per slot in .pi frontmatter; the tail is always Tier-0; a tilde cools by one number, operator-approved.
  8. Extract the tail once. One shared runtime; cards carry only frontmatter + scaffold + judgment slots.
  9. Decoder cannot hallucinate. nous understand() is the read side; DERIVED IDS carry the decoder version; bad rev rebuilds from RAW byte-identical.
  10. Cold host behind a dispatch seam. clauderun / Vertex / local CLI swap at the dispatcher without touching any card; keyless via gcp-bridge ADC→Vertex.
  11. Wire protocol only into Purcius (NTRP0001, wire over TLS); foreign-AI fan-out stays direct-HTTPS.
  12. FQDN = operator identity (CF verify + TOTP; one root key never leaves the machine; <name>US/vault).
  13. Signals mandatory. Every tilde emits one sealed Signal from the shared tail; local queue on mesh failure; allowlist-gated delivery.
  14. Cross-Platform From Day One: Win+Mac+Linux compile + smoke in the same ship cycle; MinGW UCRT the WDAC-trusted Windows path.
  15. Board + versioning discipline: triples, Fibonacci, verify-loop pairing (~a~t), Kaizen K-board, frozen historical artifacts; v0 · rN · date · pts; no co-author lines.
  16. a-d-d is human-owned (Rule 10): Nameplate name, PRACTICES #13, spec changes are proposals awaiting approval.
  17. Done = production, externally verified (Rule 9): a third party verifies with HTTP 200 / dig / a fresh-machine build before any Done.
  18. Plan shape honored + this banner stays until approved.

Unknowns named explicitly

  • Where Arc A runs — on the metal.ce repo, on metal-desktop's tools tree, or on the consolidated repo? The Catalog store is on the primes regardless, but the .pi engine (A1–A3) has a home question. Confirm at A0.
  • clauderun revival stability — the CliWorker lock-up fixes are believed sufficient (Agent SDK query(), pre-seeded settings, non-root, TERM=dumb); unproven under sustained Cold load. Local CLI is the fallback behind the seam.
  • Catalog visibility scoping detail — exactly which entries are public vs operator-scoped, and how policy resolves a requester's entitlement over the wire. FC-B flagged the direction; the tiering is unspecified.
  • DoD re-sync blast radius — re-syncing commands.md to the 10-item display may touch more crossrefs than A0 assumes (the 8-vs-10 fork has been drifting). Audit before renumbering.
  • served-by: none-yet honesty — how many of the ~50 skills have NO wire verb today (roadmap rows, not product)? The Catalog must not over-promise. Count at A4.
  • Sealed-IDS record kinds — the DERIVED IDS + queued-Signal seal formats depend on nous/security specs not in the DE tree; stability + pull path unknown.
  • CE origin drift — the parity target itself; A0 re-baselines and every downstream phase inherits what moved.
  • Nameplate — the pattern name is unblessed (Rule 10); until then the projection move is unnamed in the catalog.
  • Prime/relay deploy date — wholly external; B6's calendar anchor.
  • WDAC under automation — metal-desktop.exe + gcc blocked from Claude's sub-shell; interactive-terminal launch covers the operator path, CI-style verify loops unknown.

When To Revisit the v3 triggers

  • A1 fails the seam — if ~config.pi can't replay Tier-0 data-driven in roughly the promised parser + dispatch, the execution model (not the phase list) is wrong: back to ~d.
  • The Catalog can't serve patterns/skills as entity types — if the live store's schema resists type=pattern without new API, A4 re-opens and the “extend, don't invent” premise is re-examined.
  • DoR item 5 proves noisy or wrong for a tilde class in real use — retune the class-scoping in the one shared line; a pattern of retunes = revisit the contract.
  • clauderun locks up under load — fall back to local CLI behind the seam; if the seam itself leaks, A8 re-opens.
  • A0's origin re-read moves the target — any moved DoD/Signals/biRT surface re-baselines the phases: v3 before Arc B.
  • Prime deploys — B6 unblocks; resequence forward of whatever is in flight.
  • Any drift between the approved a-d-d spec and implementation (Rule 11) stops the tilde and flows up; two stops in one phase = plan v3.
