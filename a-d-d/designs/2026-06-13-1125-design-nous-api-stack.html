Fact Check API  ·  Market Research API

Thin C# edges (meraki-bridge pattern). Each is a strategy = a composition of nous.api verbs:
  • Fact Check = ask (fan-out) → judge (cross-model corroboration) → reconsider (adversarial re-exam).
  • Market Research = ask (fan-out) → summarize (consensus + outliers). Depth comes from deep-research models inside the fan-out, not a scout pipeline.
They hold no brains and no secrets — they call nous.api. The scale lives here (stateless, autoscaling).

Trust chain — the FQDN does the work the edge can't

Keys sealed to the operator, unsealed only in the prime

operator owns FQDN (Cloudflare-verified)→ pubkey published under FQDN (DNS TXT)→ vendor keys sealed to pubkey (seal v2 · X25519)→ edge relays opaque blob (blind)→ prime unseals · keys in RAM only
A fully-compromised Cloud Run edge is blind to the vendor keys and cannot subvert the sealing — it holds no key and never serves the page.

Where it runs — resolves the capacity question

  • Brains run on the prime — fanout/judge/summarize/reconsider are prime skills. "Add to one = add to all." No new VM for the logic.
  • Light / personal load → the existing e2-micro primes (Las Vegas, Hong Kong) — ~620 MB free, idle today.
  • Heavy / product load (fan-out holds many LLM responses + 38 outbound TLS calls) → restart the elite Ashburn c2-standard-8 and route product fan-out there. That tier exists for exactly this.
  • Public scale → absorbed by the stateless C# edges on Cloud Run (autoscale). The primes never see millions directly.

First moves (the gaps, in order)

  • 1 — `providers` skill: promote the 38-model table to one authoritative source (kill the receive.c / serve.c duplication). Everything downstream enumerates from it.
  • 2 — extract `fanout`: lift the parallel multi-provider engine out of serve.c into a headless intelligence/skill/fanout ({skill.json,.h,.c}) callable without a browser. Then judge, summarize, reconsider the same way.
  • 3 — nous.api verbs on the prime: add ask / judge / summarize / reconsider branches to the relay dispatcher; request/response are NTRP triples.
  • 4 — nous.api C# edge: clone meraki-bridge, add /v1/* + /relay, blind pass-through to the relay. Deploy to acmedev.
  • 5 — products: two more thin edges (or routes) composing nous.api verbs into Fact Check / Market Research.
Smallest proof: providers + fanout as skills, one ask verb on the prime, one POST /v1/ask on the edge → a curl from outside returns a 38-model answer. That single thread proves the whole spine.
